# Задача о рюкзаке: классическая, восстановление ответа, неограниченная

Есть $n$ предметов, у $i$-го вес $w_i$ и стоимость $c_i$, и рюкзак вместимости $W$. Нужно выбрать предметы так, чтобы их суммарный вес не превышал $W$, а суммарная стоимость была максимальной.

---

## Основные идеи

1. **Любое решение — это «да/нет» про каждый предмет.** Других решений нет.
2. **Одинаковую подзадачу достаточно посчитать один раз** и запомнить (как в Фибоначчи с запоминанием: $O(n)$ вместо экспоненты).
3. **Время ДП ≈ число состояний × работа на одно состояние.**

---

## 1. Перебор: $2^n$ вариантов

У каждого предмета 2 исхода, и решения независимы:
$$
\underbrace{2 \cdot 2 \cdot \ldots \cdot 2}_{n} = 2^n.
$$
Это **не** $n!$: $n!$ считает порядки, а в рюкзаке порядок не важен, важно только *какие* предметы внутри.

Пример ($W = 5$):

| предмет | вес | стоимость |
|---|---|---|
| 1 | 2 | 3 |
| 2 | 3 | 4 |
| 3 | 4 | 5 |

Из $2^3 = 8$ вариантов лучший из тех, что влезают, — предметы 1 и 2, стоимость **7**.

Проблема: $2^{30} \approx 10^9$, а $2^{100}$ не переберёт никто.

## 2. В переборе повторяются ситуации

$W = 10$, предметы весов 2, 3, 5, дальше ещё предметы $4..n$.
- Путь X: взяли 1 и 2 → занято 5.
- Путь Y: взяли только 3 → занято 5.

Дальше обоим нужно решить **одну и ту же** задачу: те же оставшиеся предметы, то же свободное место. Что уже лежит в рюкзаке, на дальнейший выбор не влияет.

## 3. Состояние

Вся история решений сжимается в два числа: какие предметы ещё не рассмотрены и сколько места свободно. Предметы рассматриваем с конца, тогда «не рассмотрены» = «первые $i$»:

$$
dp[i][w] = \text{лучшая стоимость из первых } i \text{ предметов при свободном месте } w.
$$

**Пути ≠ состояния.** Путей $2^n$, а состояний
$$
(n+1)(W+1),
$$
потому что много путей сходятся в одно состояние. Пример: $n = 100$, $W = 1000$ → путей $\approx 10^{30}$, состояний $\approx 10^5$.

## 4. Переход

Решаем про $i$-й предмет:
- **не берём** → $(i-1,\ w)$, ничего не получаем;
- **берём** (если $w_i \le w$) → $(i-1,\ w - w_i)$, получаем $c_i$.

$$
dp[i][w] = \max\big(dp[i-1][w],\ dp[i-1][w - w_i] + c_i\big), \qquad dp[0][w] = 0.
$$

**Влезает ≠ выгодно.** Всегда сравниваем **обе** ветки.

## 5. Как считать клетку в таблице

1. «Не берём»: клетка **прямо сверху**.
2. «Берём»: строка выше, **влево на $w_i$** столбцов, **плюс $c_i$**.
3. Записываем большее.

![Как считать клетку dp[i][5]](knapsack-cell.png)

То же самое таблицей. Считаем клетку $dp[i][5]$, предмет $i$ имеет вес 3 и стоимость 4:

|  | w=0 | w=1 | w=2 | w=3 | w=4 | w=5 |
|---|---|---|---|---|---|---|
| строка $i-1$ | 0 | 0 | **3** ← «берём» | 3 | 3 | **3** ← «не берём» |
| строка $i$ | | | | | | **?** |

| ветка | откуда берём число | расчёт |
|---|---|---|
| не берём | строка выше, **тот же** столбец $w = 5$ | $3$ |
| берём | строка выше, столбец $w - w_i = 5 - 3 = 2$, плюс стоимость | $3 + 4 = 7$ |
| итог | большее из двух | $dp[i][5] = \max(3, 7) = 7$ |

Порядок заполнения: **строки сверху вниз**, потому что каждая клетка строки $i$ использует только строку $i-1$, которая уже готова.

Таблица для примера:

| $i \backslash w$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 1 (вес 2, ст. 3) | 0 | 0 | 3 | 3 | 3 | 3 |
| 2 (вес 3, ст. 4) | 0 | 0 | 3 | 4 | 4 | 7 |
| 3 (вес 4, ст. 5) | 0 | 0 | 3 | 4 | 5 | **7** |

Ответ — правый нижний угол $dp[n][W]$.

Разбор двух клеток:
- $dp[3][4]$: не берём $= 4$, берём $= dp[2][0] + 5 = 5$ → **5** (выиграло «берём»).
- $dp[3][5]$: не берём $= 7$, берём $= dp[2][1] + 5 = 5$ → **7** (выиграло «не берём»).

## 6. Код на C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n, W;
    cin >> n >> W;
    vector<int> wt(n + 1), c(n + 1);
    for (int i = 1; i <= n; i++) cin >> wt[i] >> c[i];

    vector<vector<long long>> dp(n + 1, vector<long long>(W + 1, 0)); // строка 0 = база

    for (int i = 1; i <= n; i++)
        for (int w = 0; w <= W; w++) {
            dp[i][w] = dp[i - 1][w];                                   // не берём
            if (wt[i] <= w)
                dp[i][w] = max(dp[i][w], dp[i - 1][w - wt[i]] + c[i]); // берём
        }

    cout << dp[n][W] << '\n';
}
```

Время $O(n \cdot W)$: $(n+1)(W+1)$ состояний × $O(1)$.

## 7. Восстановление ответа

Каждая клетка получилась одним из двух способов. Смотрим, каким именно, и идём по этой стрелке обратно.

1. Старт в $(n, W)$.
2. Пока $i > 0$:
   - $dp[i][w] = dp[i-1][w]$ → предмет $i$ не нужен;
   - иначе → предмет $i$ взят, $w \mathrel{-}= w_i$;
   - $i \mathrel{-}= 1$.

```cpp
vector<int> taken;
int w = W;
for (int i = n; i >= 1; i--)
    if (dp[i][w] != dp[i - 1][w]) {
        taken.push_back(i);
        w -= wt[i];
    }
```

Маршруты по таблице:
- $W = 5$: $dp[3][5]=7 = dp[2][5]$ → 3 не берём; $dp[2][5]=7 \ne dp[1][5]=3$ → 2 взят, $w=2$; $dp[1][2]=3 \ne dp[0][2]=0$ → 1 взят, $w=0$. Набор **{1, 2}**.
- $W = 4$: $dp[3][4]=5 \ne dp[2][4]=4$ → 3 взят, $w=0$; дальше числа не меняются. Набор **{3}**.

Для восстановления нужна полная двумерная таблица.

## 8. Вариация: неограниченный рюкзак

Каждого предмета сколько угодно копий. После взятия копии место уменьшилось, а предмет **по-прежнему доступен**, поэтому $i$ не меняется:

$$
dp[i][w] = \max\big(dp[i-1][w],\ dp[\mathbf{i}][w - w_i] + c_i\big).
$$

Отличие от рюкзака 0/1 — один индекс. «Берём» смотрит в **свою** строку, влево на $w_i$, поэтому строку заполняем слева направо.

Пример: один предмет (вес 2, ст. 3). Строка 1: $0, 0, 3, 3, 6, 6$. $dp[1][4] = dp[1][2] + 3 = 6$ — две копии.

```cpp
dp[i][w] = max(dp[i][w], dp[i][w - wt[i]] + c[i]); // было dp[i - 1][...]
```

Восстановление: если предмет взяли, $i$ **не** уменьшаем (могли взять ещё копию). Уменьшаем $i$ только на ветке «не берём».
